# Espresso Physics Simulator (v3.0) ☕

最新のエスプレッソ抽出科学と多孔質流体力学に基づくリアルタイム物理シミュレーターです。豆の粉砕からタンピング、エスプレッソ抽出までをアニメーションとグラフで可視化します。

## 主な機能

- **リアルタイム物理シミュレーション**: 焙煎度（Agtron）、挽き目、ドーズ量、タンピング圧、抽出温度・圧力プロファイルなどのパラメータ変更にリアルタイム連動
- **Basic / Advanced モード切替**: 初心者向けの基本設定から、詳細な物理パラメータ編集まで対応
- **抽出アニメーション & グラフ可視化**: 粉砕・タンピング・抽出・クレマ形成までの視覚アニメーションと各種チャート表示
- **マイレシピ管理 & URL共有**: レシピの保存・呼び出し・URLでの共有機能

## ディレクトリ構成

- `index.html` — メインアプリケーション画面
- `index.css` — デザインシステム・スタイル定義
- `js/` — シミュレーションエンジンおよびUI制御スクリプト
  - `main.js` / `app.js` — コア物理エンジン・アプリケーションロジック
  - `ui/` — アニメーション、チャート、コントロール、圧力プロファイルエディタ
- `assets/img/` — シミュレーター用ビジュアルアセット

## 使い方

ブラウザで `index.html` を開くか、GitHub Pages の公開URLにアクセスするだけで動作します（ビルド手順や外部サーバーは不要です）。
